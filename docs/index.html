Gander: a dashboard, GUI and cost monitor for Claude Code agents

See every Claude Code session on one floor. Get pinged the moment one needs you, even on your phone. Know what it all costs. Stop a bad command before it runs. Free, local, MIT.

▶ Try the live demo, nothing to install Install GitHub

Each goose is a Claude Code session: thinking, coding, spawning a sub-agent, waiting on you, erroring, done. Live.

What it does

Live floor

Every session and sub-agent, across all your projects and machines, as a web user interface fed by Claude Code's own hooks.

Needs-you alerts

Who is waiting on a yes or no, with desktop, phone, Telegram and Slack alerts. Allow or Deny from anywhere, in every permission mode.

Cost monitor

Spend per session and per project, runaway alerts, budgets with a hard stop, and where the money went.

Danger guard

Destructive shell commands are held until you click Allow once. Works even with permissions bypassed.

Task queue

Line up goals per project; the bridge starts them in worktrees and merges only green branches.

Connector and voice

A read-only MCP server so claude.ai can query it, and "hey Gander" voice control in the browser.

Install in one line

/plugin marketplace add weellio/gander
/plugin install gander@gander

Type that in any Claude Code session. Or clone the repo and run node install.js. Windows, macOS and Linux; Node 18 or newer.
